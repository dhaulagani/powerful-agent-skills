# Ponytail (Git Guardrails & Safe Commits)

> Intercepts and blocks dangerous git commands (force push, reset --hard, dirty branches) for AI agents.

## 🚀 Quick Install for AI Agents

### Install in Antigravity / Gemini CLI:
```bash
git clone https://github.com/ponytail-agent/ponytail ~/.gemini/config/skills/ponytail
```

### Install in Claude Code:
```bash
git clone https://github.com/ponytail-agent/ponytail ~/.claude/skills/ponytail
```

### Install in Current Project (.agents/skills):
```bash
mkdir -p .agents/skills/ponytail
curl -sSL https://raw.githubusercontent.com/dhaulagani/powerful-agent-skills/main/skills/ponytail/SKILL.md -o .agents/skills/ponytail/SKILL.md
```
