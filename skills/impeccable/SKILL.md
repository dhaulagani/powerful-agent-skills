> Stops AI coding slop: removes robotic generic comments, enforces accessible contrast, and cleans code prose.

## 🚀 Quick Install for AI Agents

### Install in Antigravity / Gemini CLI:
```bash
git clone https://github.com/antislop/antislop ~/.gemini/config/skills/impeccable
```

### Install in Claude Code:
```bash
git clone https://github.com/antislop/antislop ~/.claude/skills/impeccable
```

### Install in Current Project (.agents/skills):
```bash
mkdir -p .agents/skills/impeccable
curl -sSL https://raw.githubusercontent.com/dhaulagani/powerful-agent-skills/main/skills/impeccable/SKILL.md -o .agents/skills/impeccable/SKILL.md
```
