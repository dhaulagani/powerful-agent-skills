# DeepTutor

> Guides coding agents to generate Socratic code explainers, exercise scaffolding, and conceptual breakdowns.

## 🚀 Quick Install for AI Agents

### Install in Antigravity / Gemini CLI:
```bash
git clone https://github.com/deeptutor-ai/deeptutor ~/.gemini/config/skills/deeptutor
```

### Install in Claude Code:
```bash
git clone https://github.com/deeptutor-ai/deeptutor ~/.claude/skills/deeptutor
```

### Install in Current Project (.agents/skills):
```bash
mkdir -p .agents/skills/deeptutor
curl -sSL https://raw.githubusercontent.com/dhaulagani/powerful-agent-skills/main/skills/deeptutor/SKILL.md -o .agents/skills/deeptutor/SKILL.md
```
