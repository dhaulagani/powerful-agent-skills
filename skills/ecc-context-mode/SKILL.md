## 🚀 Quick Install for AI Agents

### Install in Antigravity / Gemini CLI:
```bash
git clone https://github.com/mksglu/context-mode ~/.gemini/config/skills/ecc-context-mode
```

### Install in Claude Code:
```bash
git clone https://github.com/mksglu/context-mode ~/.claude/skills/ecc-context-mode
```

### Install in Current Project (.agents/skills):
```bash
mkdir -p .agents/skills/ecc-context-mode
curl -sSL https://raw.githubusercontent.com/dhaulagani/powerful-agent-skills/main/skills/ecc-context-mode/SKILL.md -o .agents/skills/ecc-context-mode/SKILL.md
```
