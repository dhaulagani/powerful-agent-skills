## 🚀 Quick Install for AI Agents

### Install in Antigravity / Gemini CLI:
```bash
git clone https://github.com/opencode-ai/opencode ~/.gemini/config/skills/opencode
```

### Install in Claude Code:
```bash
git clone https://github.com/opencode-ai/opencode ~/.claude/skills/opencode
```

### Install in Current Project (.agents/skills):
```bash
mkdir -p .agents/skills/opencode
curl -sSL https://raw.githubusercontent.com/dhaulagani/powerful-agent-skills/main/skills/opencode/SKILL.md -o .agents/skills/opencode/SKILL.md
```
