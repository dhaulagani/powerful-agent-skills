# Archify (Obsidian Second Brain Architecture)

> Automatically documents codebase architecture, logs architectural decision records (ADRs), and builds knowledge vault.

## 🚀 Quick Install for AI Agents

### Install in Antigravity / Gemini CLI:
```bash
git clone https://github.com/obsidian-developer/obsidian-second-brain ~/.gemini/config/skills/archify
```

### Install in Claude Code:
```bash
git clone https://github.com/obsidian-developer/obsidian-second-brain ~/.claude/skills/archify
```

### Install in Current Project (.agents/skills):
```bash
mkdir -p .agents/skills/archify
curl -sSL https://raw.githubusercontent.com/dhaulagani/powerful-agent-skills/main/skills/archify/SKILL.md -o .agents/skills/archify/SKILL.md
```
