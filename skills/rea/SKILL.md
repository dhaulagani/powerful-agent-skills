# REA (Reverse Engineering Agent)

> Autonomous reverse engineering & binary/APK attack surface inspector for AI coding agents.

## 🚀 Quick Install for AI Agents

### Install in Antigravity / Gemini CLI:
```bash
git clone https://github.com/morluto/rea ~/.gemini/config/skills/rea
```

### Install in Claude Code:
```bash
git clone https://github.com/morluto/rea ~/.claude/skills/rea
```

### Install in Current Project (.agents/skills):
```bash
mkdir -p .agents/skills/rea
curl -sSL https://raw.githubusercontent.com/dhaulagani/powerful-agent-skills/main/skills/rea/SKILL.md -o .agents/skills/rea/SKILL.md
```
