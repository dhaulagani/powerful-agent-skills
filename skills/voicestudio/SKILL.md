## 🚀 Quick Install for AI Agents

### Install in Antigravity / Gemini CLI:
```bash
git clone https://github.com/livekit/agents ~/.gemini/config/skills/voicestudio
```

### Install in Claude Code:
```bash
git clone https://github.com/livekit/agents ~/.claude/skills/voicestudio
```

### Install in Current Project (.agents/skills):
```bash
mkdir -p .agents/skills/voicestudio
curl -sSL https://raw.githubusercontent.com/dhaulagani/powerful-agent-skills/main/skills/voicestudio/SKILL.md -o .agents/skills/voicestudio/SKILL.md
```
