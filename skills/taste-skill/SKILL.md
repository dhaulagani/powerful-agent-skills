# Taste Skill (Design Taste Frontend)

> Bespoke agency-grade frontend design standards: curated typography, whitespace, and anti-template UI.

## 🚀 Quick Install for AI Agents

### Install in Antigravity / Gemini CLI:
```bash
git clone https://github.com/frontend-craft/design-taste ~/.gemini/config/skills/taste-skill
```

### Install in Claude Code:
```bash
git clone https://github.com/frontend-craft/design-taste ~/.claude/skills/taste-skill
```

### Install in Current Project (.agents/skills):
```bash
mkdir -p .agents/skills/taste-skill
curl -sSL https://raw.githubusercontent.com/dhaulagani/powerful-agent-skills/main/skills/taste-skill/SKILL.md -o .agents/skills/taste-skill/SKILL.md
```
