```bash
git clone https://github.com/karpathy/nanoGPT ~/.gemini/config/skills/karpathy-skills
```

```bash
git clone https://github.com/karpathy/nanoGPT ~/.claude/skills/karpathy-skills
```

### Install in Current Project (.agents/skills):
```bash
mkdir -p .agents/skills/karpathy-skills
```
