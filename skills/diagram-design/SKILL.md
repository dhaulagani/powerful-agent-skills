# Diagram Design (Mermaid & Penpot Architecture)

> Generates valid flowcharts, sequence diagrams, state machines, and class diagrams without syntax errors.

## 🚀 Quick Install for AI Agents

### Install in Antigravity / Gemini CLI:
```bash
git clone https://github.com/diagram-architect/agent-diagrams ~/.gemini/config/skills/diagram-design
```

### Install in Claude Code:
```bash
git clone https://github.com/diagram-architect/agent-diagrams ~/.claude/skills/diagram-design
```

### Install in Current Project (.agents/skills):
```bash
mkdir -p .agents/skills/diagram-design
curl -sSL https://raw.githubusercontent.com/dhaulagani/powerful-agent-skills/main/skills/diagram-design/SKILL.md -o .agents/skills/diagram-design/SKILL.md
```
