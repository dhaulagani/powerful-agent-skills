# Orca (Subagent Supervisor)

> High-throughput parallel subagent dispatching, progress tracking, and isolated workspace branch coordination.

## 🚀 Quick Install for AI Agents

### Install in Antigravity / Gemini CLI:
```bash
git clone https://github.com/orca-team/orca ~/.gemini/config/skills/orca
```

### Install in Claude Code:
```bash
git clone https://github.com/orca-team/orca ~/.claude/skills/orca
```

### Install in Current Project (.agents/skills):
```bash
mkdir -p .agents/skills/orca
curl -sSL https://raw.githubusercontent.com/dhaulagani/powerful-agent-skills/main/skills/orca/SKILL.md -o .agents/skills/orca/SKILL.md
```
