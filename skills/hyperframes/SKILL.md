# HyperFrames (Generative UI & Web Components)

> Renders rich interactive HTML5 widgets, inline data dashboards, and SVG visuals directly in agent chat.

## 🚀 Quick Install for AI Agents

### Install in Antigravity / Gemini CLI:
```bash
git clone https://github.com/generative-ui-team/hyperframes ~/.gemini/config/skills/hyperframes
```

### Install in Claude Code:
```bash
git clone https://github.com/generative-ui-team/hyperframes ~/.claude/skills/hyperframes
```

### Install in Current Project (.agents/skills):
```bash
mkdir -p .agents/skills/hyperframes
curl -sSL https://raw.githubusercontent.com/dhaulagani/powerful-agent-skills/main/skills/hyperframes/SKILL.md -o .agents/skills/hyperframes/SKILL.md
```
