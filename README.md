## 🤖 How Any AI Agent Can Self-Install Skills From This Repo

**Are you an AI coding agent (Antigravity, Claude Code, Cursor, Codex, OpenHands)?**
You can inspect this repository, read our machine-readable [`registry.json`](./registry.json), and install any skill into your active workspace with **1 command or 1 prompt**:

### ⚡ 1-Prompt Agent Instruction (Copy & Paste to your Agent):
```text
Fetch https://raw.githubusercontent.com/dhaulagani/powerful-agent-skills/main/registry.json and install skill '<skill_name>' (or 'all') into my skills directory.
```

### 💻 Universal CLI One-Liners:
- **Install ALL 23 Trending Skills in 1 shot:**
  ```bash
  curl -sSL https://raw.githubusercontent.com/dhaulagani/powerful-agent-skills/main/install.sh | bash -s all
  ```
- **Install on Windows (PowerShell):**
  ```powershell
  irm https://raw.githubusercontent.com/dhaulagani/powerful-agent-skills/main/install.ps1 | iex -ArgumentList 'all'
  ```
- **Install a specific skill (e.g. `superpowers`):**
  ```bash
  curl -sSL https://raw.githubusercontent.com/dhaulagani/powerful-agent-skills/main/install.sh | bash -s superpowers
  ```

## 🤖 How the Autonomous Verification Engine Works
This repository is maintained automatically by a daily background worker:
1. Every 24 hours at 00:00 UTC, an automated runner queries the GitHub API for stargazers and commit activity of the top tracked agent repos.
2. The leaderboard and [`registry.json`](./registry.json) are updated with real-time rankings.
3. Live badges and individual `SKILL.md` installation recipes are re-committed directly to `main` with concurrency locks.
